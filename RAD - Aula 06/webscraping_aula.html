01 · Introdução

O que é Web Scraping?

Web Scraping é o processo automatizado de extração de dados de páginas web. Em vez de copiar informações manualmente, escrevemos código que faz isso por nós — em escala, velocidade e precisão impossíveis para humanos.

Por que aprender Web Scraping?

Segundo o Data Never Sleeps 2024, a internet gera mais de 2,5 quintilhões de bytes de dados por dia. Grande parte disso está em páginas HTML — sem API disponível. Quem sabe extrair esses dados tem vantagem competitiva enorme.

02 · Biblioteca

BeautifulSoup4

A biblioteca mais simples e direta para parsear HTML estático. Ideal para sites que não dependem de JavaScript para renderizar conteúdo. Usa o poder do requests para baixar o HTML e o bs4 para navegar na árvore DOM.

Iniciante

✅ Quando usar BeautifulSoup?

✓ IDEAL PARA:

  • → HTML estático (sem JS)
  • → Extração rápida e simples
  • → Protótipos e scripts pontuais
  • → Sites com paginação simples
  • → Baixo volume de requisições

✗ EVITE PARA:

  • → SPAs (React, Angular, Vue)
  • → Conteúdo carregado via AJAX
  • → Interações (login, cliques)
  • → Sites com anti-bot avançado

Exemplo 1 — Estrutura Básica

python · bs4_basico.py 
import requests
from bs4 import BeautifulSoup

# 1. Fazer a requisição HTTP
url = "https://books.toscrape.com"
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"
}
response = requests.get(url, headers=headers)

# 2. Parsear o HTML
soup = BeautifulSoup(response.text, "lxml")

# 3. Encontrar elementos
titulo  = soup.find("h1").text
livros  = soup.find_all("article", class_="product_pod")

for livro in livros:
    nome  = livro.find("h3").find("a")["title"]
    preco = livro.find("p", class_="price_color").text
    print(f"{nome} — {preco}")

Exemplo 2 — Caso Real: Monitor de Preços

Scraper que extrai preços de produtos e salva em CSV para análise histórica.

python · monitor_precos.py 
import requests
from bs4 import BeautifulSoup
import pandas as pd
from datetime import datetime
import time, random

def scrape_books_page(page=1):
    url = ff"https://books.toscrape.com/catalogue/page-{page}.html"
    resp = requests.get(url, timeout=10)
    resp.raise_for_status()
    soup = BeautifulSoup(resp.text, "lxml")

    dados = []
    for item in soup.select("article.product_pod"):
        dados.append({
            "nome":  item.select_one("h3 a")["title"],
            "preco": item.select_one(".price_color").text.strip(),
            "rating": item.select_one("p.star-rating")["class"][1],
            "data":   datetime.now().isoformat(),
        })
    return dados

# Scraping com paginação automática
todos = []
for p in range(1, 6):  # 5 páginas
    print(ff"Página {p}...")
    todos.extend(scrape_books_page(p))
    time.sleep(random.uniform(1, 2.5))  # delay humano

df = pd.DataFrame(todos)
df.to_csv("precos.csv", index=False)
print(ff"✅ {len(todos)} livros salvos!")

⚡ Tratamento de Erros e Boas Práticas ▼
erros + boas práticas
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# Session com retry automático
session = requests.Session()
retry = Retry(total=3, backoff_factor=1,
               status_forcelist=[429,500,502,503])
session.mount("https://", HTTPAdapter(max_retries=retry))

# Extração segura com .get()
def safe_text(soup, selector, default=""):
    el = soup.select_one(selector)
    return el.text.strip() if el else default

# Uso:
preco = safe_text(soup, ".price_color", "N/A")
03 · Biblioteca

Selenium

O Selenium controla um browser real (Chrome, Firefox) e permite interagir com páginas dinâmicas: clicar, preencher formulários, fazer scroll, esperar elementos carregarem. É o padrão de ouro para automação de browser há mais de uma década.

Intermediário

⚡ Casos de Uso do Selenium

✓ IDEAL PARA:

  • → Sites com JavaScript pesado
  • → Login e sessões autenticadas
  • → Formulários com CAPTCHA simples
  • → Interações complexas (drag, hover)
  • → Testes de interface (QA)

⚠ LIMITAÇÕES:

  • → Mais lento que BS4
  • → Consome mais memória
  • → WebDriver precisa de sync
  • → Playwright supera em async

Exemplo 1 — Setup e Navegação Básica

python · selenium_setup.py 
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

# Configurações do Chrome
options = webdriver.ChromeOptions()
options.add_argument("--headless")         # sem janela
options.add_argument("--no-sandbox")
options.add_argument("--disable-dev-shm-usage")
options.add_argument("--window-size=1920,1080")

# Inicializar driver com gerenciador automático
driver = webdriver.Chrome(
    service=Service(ChromeDriverManager().install()),
    options=options
)

try:
    driver.get("https://quotes.toscrape.com/js/")

    # Espera explícita — aguarda elemento aparecer
    wait = WebDriverWait(driver, 10)
    wait.until(EC.presence_of_element_located(
        (By.CLASS_NAME, "quote")
    ))

    # Extrair citações renderizadas por JS
    quotes = driver.find_elements(By.CLASS_NAME, "quote")
    for q in quotes:
        texto  = q.find_element(By.CLASS_NAME, "text").text
        autor  = q.find_element(By.CLASS_NAME, "author").text
        print(ff"{autor}: {texto[:60]}...")
finally:
    driver.quit()  # SEMPRE fechar o driver

Exemplo 2 — Caso Real: Login + Scraping de Área Restrita

Automação de login e extração de dados de área autenticada — padrão usado em portais bancários, ERP e intranets.

python · selenium_login.py 
from selenium.webdriver.common.keys import Keys
import time

def login_e_scrape(driver, user, pwd):
    driver.get("https://quotes.toscrape.com/login")

    # Preencher formulário
    campo_user = driver.find_element(By.ID, "username")
    campo_pwd  = driver.find_element(By.ID, "password")

    campo_user.clear()
    campo_user.send_keys(user)
    campo_pwd.send_keys(pwd)
    campo_pwd.send_keys(Keys.RETURN)

    # Aguardar redirecionamento
    WebDriverWait(driver, 5).until(
        EC.url_contains("/")
    )
    print("✅ Login realizado!")

    # Scroll infinito: carregar mais conteúdo
    last_height = driver.execute_script(
        "return document.body.scrollHeight"
    )
    while True:
        driver.execute_script(
            "window.scrollTo(0, document.body.scrollHeight);"
        )
        time.sleep(2)
        new_height = driver.execute_script(
            "return document.body.scrollHeight"
        )
        if new_height == last_height:
            break
        last_height = new_height

    return driver.page_source
04 · Biblioteca

Playwright

O Playwright é a ferramenta moderna de automação de browser, criada pela Microsoft. Suporta Chromium, Firefox e WebKit com API async nativa. É mais rápido, mais confiável e mais fácil de usar que o Selenium para scraping moderno.

Avançado

Exemplo 1 — Scraping Async com Playwright

python · playwright_basico.py 
import asyncio
from playwright.async_api import async_playwright

async def main():
    async with async_playwright() as p:
        # Lançar browser (chromium, firefox, webkit)
        browser = await p.chromium.launch(headless=True)

        # Criar contexto (isolamento total de cookies/cache)
        context = await browser.new_context(
            viewport={"width": 1280, "height": 720},
            user_agent="Mozilla/5.0 (Windows NT 10.0; Win64)"
        )
        page = await context.new_page()

        # Navegar e esperar carregamento completo
        await page.goto(
            "https://quotes.toscrape.com/js/",
            wait_until="networkidle"
        )

        # Locator moderno — mais estável que find_elements
        citacoes = await page.locator(".quote").all()

        for cit in citacoes:
            texto = await cit.locator(".text").inner_text()
            autor = await cit.locator(".author").inner_text()
            print(ff"[{autor}] {texto[:60]}")

        await browser.close()

asyncio.run(main())

Exemplo 2 — Avançado: Interceptar Requisições de API

Técnica poderosa: capturar as chamadas XHR/fetch que o site faz e pegar os dados JSON diretamente — sem parsear HTML!

python · playwright_intercept.py 
import asyncio, json
from playwright.async_api import async_playwright

api_data = []

async def capturar_api():
    async with async_playwright() as p:
        browser = await p.chromium.launch()
        page    = await browser.new_page()

        # Interceptar todas as respostas de rede
        async def handle_response(response):
            if "api" in response.url and response.status == 200:
                try:
                    data = await response.json()
                    api_data.append(data)
                    print(ff"✅ API capturada: {response.url}")
                except:
                    pass

        page.on("response", handle_response)

        await page.goto("https://site-alvo.com",
                         wait_until="networkidle")

        # Clicar em elementos para disparar mais requests
        await page.click("button#load-more")
        await page.wait_for_load_state("networkidle")

        # Screenshot para debug
        await page.screenshot(path="debug.png", full_page=True)

        with open("dados.json", "w") as f:
            json.dump(api_data, f, ensure_ascii=False, indent=2)
        await browser.close()

asyncio.run(capturar_api())

Exemplo 3 — Scraping em Paralelo (Alta Performance)

python · playwright_paralelo.py 
import asyncio
from playwright.async_api import async_playwright

URLS = [
    "https://books.toscrape.com/catalogue/page-1.html",
    "https://books.toscrape.com/catalogue/page-2.html",
    "https://books.toscrape.com/catalogue/page-3.html",
]

async def scrape_page(browser, url):
    page = await browser.new_page()
    await page.goto(url)
    titulos = await page.locator("h3 a").all_inner_texts()
    await page.close()
    return {"url": url, "titulos": titulos}

async def main():
    async with async_playwright() as p:
        browser = await p.chromium.launch()

        # Scrapar 3 páginas AO MESMO TEMPO
        tasks  = [scrape_page(browser, u) for u in URLS]
        results = await asyncio.gather(*tasks)

        for r in results:
            print(ff"{r['url']}: {len(r['titulos'])} livros")
        await browser.close()

asyncio.run(main())

Comparativo Técnico

Escolher a ferramenta certa depende do tipo de site, volume de dados, necessidade de interação e performance desejada. Use este guia para decidir.

Critério BeautifulSoup4 Selenium Playwright
JavaScript NÃO SIM SIM
Velocidade ⚡ Muito rápido 🐢 Lento 🚀 Rápido
Async nativo NÃO NÃO SIM
Consumo de RAM Baixo Alto Médio
Curva de aprendizado Fácil Média Média
Interceptar rede NÃO NÃO SIM

Qual ferramenta escolher?

O site usa JavaScript para renderizar conteúdo?

BeautifulSoup4 + requests ~8 segundos

Playwright async (1 worker) ~60 segundos

07 · Importante

Ética, Legalidade & Boas Práticas

Web Scraping é uma faca de dois gumes. Usado com responsabilidade, é uma ferramenta poderosa. Usado sem critério, pode causar danos e problemas legais sérios.

📋 Verificar o arquivo robots.txt ▼

O robots.txt indica quais partes do site o dono permite que crawlers acessem. Sempre verifique antes de scrapar.

python · verificar robots.txt
from urllib.robotparser import RobotFileParser

def pode_scrapar(url, user_agent="*"):
    rp = RobotFileParser()
    from urllib.parse import urljoin, urlparse
    base = ff"{urlparse(url).scheme}://{urlparse(url).netloc}"
    rp.set_url(ff"{base}/robots.txt")
    rp.read()
    return rp.can_fetch(user_agent, url)

# Uso:
if pode_scrapar("https://exemplo.com/pagina"):
    print("✅ Permitido")
else:
    print("❌ Proibido pelo robots.txt")
⚖️ Aspectos Legais no Brasil ▼

A LGPD (Lei 13.709/2018) regula o tratamento de dados no Brasil. Pontos importantes para scrapers:

  • → Dados públicos podem ser coletados para finalidade legítima (pesquisa, análise, jornalismo)
  • → Dados pessoais (nome, CPF, e-mail) exigem base legal e não devem ser revendidos
  • → Termos de Uso dos sites podem proibir scraping — violar pode gerar processo
  • → DDoS involuntário: scripts sem rate limiting podem sobrecarregar servidores (crime)
🛡️ Boas Práticas Técnicas ▼
  1. Rate LimitingAdicione delays aleatórios entre requisições: time.sleep(random.uniform(1, 3))
  2. Respeitar robots.txtSempre verificar o arquivo antes de iniciar qualquer crawler.
  3. User-Agent honestoIdentifique seu bot: "MeuBot/1.0 (contato@email.com)"
  4. Caching localSalve o HTML baixado para não requisitar o mesmo conteúdo múltiplas vezes.
  5. Horário de baixo tráfegoAgende scrapers para rodar de madrugada, minimizando impacto.
  6. Contato com o siteSe precisar de dados em grande volume, entre em contato e peça uma API ou acesso autorizado.
⚠️ Atenção: Scrapers que geram carga excessiva em servidores, coletam dados pessoais sem autorização ou violam termos de uso podem resultar em bloqueio de IP, ação judicial ou problemas com a LGPD. Sempre atue com responsabilidade.
